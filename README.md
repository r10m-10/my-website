# My Builder Page

## About
This is a basic Builder Page that I have made using simple HTMl and CSS showcasing my projects and introducing myself.

## Features

- Introduction
- Project cards
- contact section

## Projects

### Math Suite:

Math Suite is a symbolic math toolkit with six different tools that use the same expression syntax. It is built around a hand-written tokenizer and parser that produces Abstract Syntax Trees (ASTs).

[Visit Math Suite](https://mathsuite-psi.vercel.app)

### Tally Auto

Tally Auto is an automation script that takes a CSV file and adds products to a custom Tally product-ordering form.

[Visit Tally Auto](https://tally-auto.vercel.app)
